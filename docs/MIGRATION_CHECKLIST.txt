📋 PRE-MIGRATION (5 minutes)

On Jetson:
  □ Verify services running: docker-compose ps
  □ All containers show "Up" status
  □ Note your Jetson IP: hostname -I
  
On Desktop:
  □ Backup old notebook: fall_detection_control_center.ipynb
  □ Create project directory: mkdir ~/fall-detection-operator

📦 INSTALLATION (10 minutes)

Copy Files:
  □ operator_interface.py → ~/fall-detection-operator/
  □ sensor_simulator.ipynb → ~/fall-detection-operator/
  □ requirements-operator.txt → ~/fall-detection-operator/

Install Dependencies:
  □ cd ~/fall-detection-operator
  □ python3 -m venv venv (optional but recommended)
  □ source venv/bin/activate
  □ pip install -r requirements-operator.txt
  □ pip install jupyter numpy pandas matplotlib paho-mqtt

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚙️  CONFIGURATION (5 minutes)

Sensor Simulator:
  □ jupyter notebook
  □ Open sensor_simulator.ipynb
  □ Update JETSON_IP = "192.168.x.x" in configuration cell
  □ Save notebook (Ctrl+S)

Operator Interface (optional):
  □ Edit operator_interface.py
  □ Update DEFAULT_JETSON_IP = "192.168.x.x"
  □ Save file

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🧪 TESTING (10 minutes)

Test Operator Interface:
  □ streamlit run operator_interface.py
  □ Browser opens to http://localhost:8501
  □ Enter Jetson IP in sidebar
  □ Click "Connect" button
  □ See "🟢 Connected" status
  □ Click "Get Status" in sidebar
  □ Dashboard shows system information

Test Sensor Simulator:
  □ jupyter notebook (new terminal)
  □ Open sensor_simulator.ipynb
  □ Run cells: Config → Imports → SensorSimulator → Connect
  □ See "✅ Connected to MQTT Broker"
  □ Navigate to "Mode 3: Manual Single Reading"
  □ Run: simulator.send_reading(is_fall=False, operational_mode="inference")
  □ See "✅ Sent normal inference reading"

Verify Data Flow:
  □ Check Operator Interface Dashboard
  □ OR check Jetson logs: docker logs --tail=20 mqtt-influx-bridge
  □ Should see message received

✅ END-TO-END VERIFICATION (5-10 minutes)

Quick Inference Test:
  □ Operator Interface → Inference Control
  □ Click "Load Best Model"
  □ Click "Switch to Inference Mode"
  
  □ Sensor Simulator → Mode 2: Inference Data
  □ Run: generate_inference_data(duration=30, fall_probability=0.1)
  
  □ Operator Interface → Live Monitoring
  □ Click "Refresh Data"
  □ See predictions appearing
  □ See graphs updating

Optional - Training Test:
  □ Sensor Simulator → Mode 1: Training Data
  □ Run: generate_training_data(num_samples=50, fall_percentage=10.0)
  □ Wait 30 seconds
  
  □ Operator Interface → Training Control
  □ Set epochs to 10
  □ Click "Start Training"
  □ Check logs: docker logs -f custom-lstm-detector
  □ Wait for completion

🆘 QUICK TROUBLESHOOTING

Can't Connect:
  → Verify Jetson IP: ping JETSON_IP
  → Check MQTT: docker logs mosquitto
  → Check firewall: sudo ufw status

No Predictions:
  → Load model: Inference Control → "Load Best Model"
  → Switch mode: Inference Control → "Switch to Inference"
  → Check logs: docker logs custom-lstm-detector

Data Not Flowing:
  → Check bridge: docker logs mqtt-influx-bridge
  → Restart broker: docker-compose restart mosquitto
  → Verify topics match in simulator and bridge
