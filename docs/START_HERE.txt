🎓 TYPICAL WORKFLOWS

Training a Model (Manual Mode):
  1. Sensor Simulator: Generate 500+ labeled samples
  2. Wait 30 seconds for data ingestion
  3. Operator Interface → Training Control: Click "Start Training"
  4. Wait for completion (5-15 minutes)
  5. Operator Interface → Training Control: Click "Validate"
  6. Operator Interface → Inference Control: Click "Load Best Model"

Running Inference:
  1. Operator Interface → Inference Control: Click "Load Best Model"
  2. Operator Interface → Inference Control: Click "Switch to Inference"
  3. Sensor Simulator: Generate sensor data (continuous)
  4. Operator Interface → Live Monitoring: Watch predictions in real-time

💻 DEPLOYMENT CHECKLIST

Backend (Jetson - One Time Setup):
  □ Deploy Docker services (already done if existing system)
  □ Verify all containers running: docker-compose ps
  □ Check InfluxDB accessible: http://<JETSON_IP>:8086
  □ Verify MQTT broker: mosquitto_sub -h <JETSON_IP> -t test

Operator Interface (Desktop - Each Session):
  □ Install dependencies: pip install -r requirements-operator.txt
  □ Run interface: streamlit run operator_interface.py
  □ Opens in browser: http://localhost:8501
  □ Connect to Jetson IP
  □ Verify connection: Click "Get Status"

Sensor Simulator (Desktop - Each Session):
  □ Install Jupyter: pip install jupyter
  □ Start Jupyter: jupyter notebook
  □ Open sensor_simulator.ipynb
  □ Update Jetson IP in configuration
  □ Run cells to connect and generate data

🔧 TECHNICAL DETAILS

Components (Unchanged on Jetson):
  - MQTT Broker (Mosquitto) - Port 1883
  - MQTT Bridge - Routes data to InfluxDB
  - InfluxDB - Stores time-series data (Ports 8086)
  - LSTM Service - ML training & inference
  - Grafana - Visualization (Port 3000)

New Components (Desktop/Laptop):
  - Operator Interface - Web control panel (Port 8501)
  - Sensor Simulator - Data generator (Jupyter)

Data Flow:
  Sensor Simulator → MQTT → Bridge → InfluxDB → LSTM Service
       ↓                                            ↓
  (Generates)                               (Trains/Predicts)
                                                    ↓
                          Operator Interface ← Predictions
